Free tool for RevOps & sales leaders

How much of your forecast rests on stale data?

Drop in a Salesforce opportunities export. In a few seconds you'll see which open deals have past-due close dates, no next step, or no recent activity, how much pipeline value that puts at risk, and who to talk to first.

Your file is read by your browser and never uploaded. There is no server-side storage and no analytics. The optional AI summary sends only aggregated numbers, with rep names replaced by labels, and only when you click it.

Or drop a .csv file here

Works best with an Opportunities report exported as "Details Only". Column names are matched automatically, and you can fix the mapping afterwards.

How to export the right report from Salesforce (2 minutes)
  1. In Salesforce, open Reports → New Report and choose the Opportunities report type.
  2. Set the filters to All opportunities (or your team), and a date range that covers your open pipeline.
  3. Add these columns where you have them: Opportunity Owner, Opportunity Name, Account Name, Stage, Amount, Close Date, Created Date, Next Step, Last Activity, Forecast Category, Probability (%), Stage Duration. Only Stage, Amount and Close Date are required. Each extra column turns on another check.
  4. Save, then choose Export → Details Only → Comma Delimited .csv.
  5. Drop the file here. If you'd rather not use real data, the demo button loads a synthetic pipeline in the same format.
